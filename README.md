# 🛒 Online Marketplace Platform

A complete online marketplace where users can **buy and sell products** with each other—similar to Alibaba. Built using **PHP** for the backend and **JavaScript (Fetch API)** for dynamic frontend behavior.

---

## 💡 Overview

This platform allows any user to:
- 📦 Upload and sell products
- 🛍️ Buy products from other users
- 🧾 View purchase & sales history
- 🔔 Receive notifications
- 🔍 Search/filter products
- 👮‍♂️ (Admin) Manage users and product listings

---

## ⚙️ Technologies Used

- **Frontend:** HTML, CSS, JavaScript (Fetch API)
- **Backend:** PHP
- **Database:** MySQL
- **Storage:** LocalStorage (for cart items, temporary state)

---

## 🚀 Features

### 🧑‍💼 General User Features
- Register and login
- Upload product (title, price, quantity, images, etc.)
- Apply coupon codes (if available)
- Add to cart and confirm purchase
- View buying and selling history
- Receive notifications when someone buys their product

### 🛒 Cart System
- Store cart data in localStorage
- Update quantity or remove items
- Confirm purchases directly from the cart

### 📂 History & Notifications
- Purchase and sale history are stored and viewable
- Notifications shown for sellers when a buyer confirms an order

### 🛠️ Admin Panel
Admins have access to a secure panel where they can:
- View all registered users
- View all products posted
- Delete any inappropriate or expired products
- Monitor activity for moderation
